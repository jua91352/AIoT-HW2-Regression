三、CRISP-DM：自迴歸股價預測

3.1 Business Understanding 商業理解

  • 問題：用過去 p 個交易日的收盤價，預測下一個交易日的收盤價，並往後預測 20 個交易日、附上預測區間。
  • 模型：自迴歸 AR(p)：yt = c + φ₁yt−1 + … + φpyt−p + εt。本質上是把「前幾天的價格」當成特徵的多元線性回歸，因此可以沿用 OLS、信賴區間與預測區間。
  • 使用者與決策：學生與投資人了解價格的慣性與不確定性；預測區間用來評估合理價格範圍與風險，而不是買賣訊號。
  • 成功標準：測試期 RMSE 低於 Naive 基準（明天價格 = 今天價格）；95% 預測區間的實際涵蓋率接近 95%。

3.2 Data Understanding 資料理解

  • 資料來源：Yahoo Finance 台積電 2330.TW 日線資料（finance.yahoo.com/quote/2330.TW），由本平台的 /api/stock 下載並內建於網站。
  • 期間：2021-10-14 ～ 2026-10-14，共 1,213 個交易日；欄位為 Date、Open、High、Low、Close、Adj Close、Volume，預測目標為 Close。
  • 走勢：收盤價從 573 元漲到 2,490 元；測試期第一天為 1,425 元，測試期內上漲約 75%。
  • 自我相關：ACF 緩慢遞減、PACF 在第 1 期之後落入信賴界線內 → 價格具強烈慣性且非定態，適合從 AR(1) 開始建模。

3.3 Data Preparation 資料準備

  1. 解析日期並由舊到新排序；移除缺失與重複日期（本資料皆為 0 筆）。
  2. 對數轉換：以 log(Close) 建模。價格越高、每日波動的金額越大；取對數後誤差變成百分比尺度，變異數較穩定，預測完再以 exp() 轉回價格。
  3. 建立落後特徵：第 t 天的特徵為前 1～p 天的值。
  4. 依時間切分、不打亂順序：訓練期 970 天（2021-10-14 ～ 2025-10-13），測試期 243 天（2025-10-14 ～ 2026-10-14），避免用未來資料預測過去。

3.4 Modeling 建模（含特徵選擇）

特徵選擇＝選擇落後期數 p。在訓練期對 p = 1～30 分別配適 AR(p)，使用相同的樣本區間比較 AIC 與 BIC。對數尺度下 AIC 與 BIC 都在 p = 1 最小；原始價格尺度下 AIC 選 p = 10、BIC 選 p = 1。BIC 懲罰較重、偏好簡單模型；兩種尺度的 BIC 都支持 AR(1)。

5.1 NotebookLM 摘要Kaggle 洪水預測的同主題解法

以 NotebookLM 研究網路上 Kaggle Playground Series S4E5（Predict the Flood）的同主題解法，摘要如下：

在 Kaggle S4E5 洪水預測競賽中，單純多元線性回歸展現出驚人的基準表現，因目標值主要由特徵總和決定，僅靠線性擬合即可達到 0.845 的 R² 分數，優於未經特徵工程的原始樹狀模型；但其限制在於無法捕捉細微的非線性殘差與交互作用，導致分數到達瓶頸。社群隨後發現此資料結構，開發出關鍵的列級特徵工程，包含計算特徵總和（fsum）、按數值大小對列特徵進行排序，以及計算列標準差、極值與高於閾值的特徵數量等統計量。

前幾名優勝解法進一步結合 CatBoost、XGBoost、LightGBM 與 AutoGluon 等多元模型，並利用 Ridge 或 Lasso 回歸對多組折外預測（OOF）進行加權集成，成功將 R² 分數提升至 0.869 以上。這給予使用多元線性回歸的學生重要啟示：線性模型是快速驗證全局規律與建立強大 Baseline 的優良起點，但若要達到極致預測精度，仍需深入進行 EDA，結合列統計特徵開發與多模型集成，才能補足單一線性模型的侷限。

七、NotebookLM 摘要股價預測的同主題解法

使用 NotebookLM 研究網路上以時間序列預測股價的同主題解法，請它比較主流方法、說明 AR 為何難以贏過 Naive，並給出建議。摘要如下（保留原文，只把公式改為一般寫法）：

以下為您整理的時間序列股價預測主流方法比較與分析摘要：

1. 主流預測方法比較

  • Naive／隨機漫步基準：做法為假設明日股價等於今日股價 (Ŷt+1 = Yt)。優點是極簡且零參數，完全無過擬合風險；缺點是無法預測趨勢轉折或波幅。
  • AR／ARIMA：利用歷史價格（自迴歸 AR）與殘差（移動平均 MA）捕獲線性規律。優點是理論完備、適合平穩序列；缺點是無法處理非線性動態，面對非平穩股價易退化。
  • GARCH：針對條件變異數建模，專注於捕捉金融市場的「波動聚集（Volatility Clustering）」現象。優點是精準評估風險與波動度，缺點是其預測標的為波動率而非價格方向。
  • LSTM (機器學習)：透過門控機制學習非線性長短期依賴。優點是擬合能力強；缺點是需要大量數據、容易過擬合高噪音股價、模型為黑盒子且常見預測滯後（Lagging）。

2. 為什麼 AR 很難贏過 Naive 基準？

根據效率市場假說（EMH），股價價格序列近似隨機漫步，其報酬率自相關性極低且高噪音。若直接對非平穩的原始股價建立 AR 模型，參數會趨近於 1，實際退化為 Naive 模型；若對差分後的平穩報酬率建模，由於信躁比極低，估計出的 AR 參數多為樣本雜訊（過擬合），使得樣本外（Out-of-Sample）預測誤差往往大於零參數的 Naive 基準。

3. 給用「線性回歸」預測股價學生的建議

  1. 切勿直接預測原始股價：原始股價是非平穩序列，直接做 OLS 迴歸會產生「偽迴歸（Spurious Regression）」及虛高 R² 的假象。
  2. 改為預測「報酬率」或「漲跌方向」：將數據轉換為平穩序列後，再結合技術指標或總體經濟特徵進行預測。
  3. 務必以 Naive Model 為對照組：採用滾動式樣本外驗證（Rolling Walk-Forward），並比較其 RMSE/MAE 是否真的擊敗簡單的 Naive Baseline。

7.2 與本作業結果的對照

NotebookLM 摘要的論點本作業的結果
對非平穩股價建立 AR 模型，參數會趨近 1、退化為 NaiveAR(1) 的 φ₁ = 1.0006（95% CI 0.9969 ～ 1.0044，涵蓋 1）；測試期 RMSE 41.762，與 Naive 的 41.908 幾乎相同，完全吻合。對數價格的一階差分就是報酬率，φ₁ ≈ 1 代表報酬率接近白噪音（Ljung-Box p = 0.190）
直接預測原始股價會出現偽迴歸與虛高的 R²訓練期 R² = 0.9965、測試期 R² = 0.9883 都很高，但 Naive 的 R² 也有 0.9882；因此本報告以 Naive 為主要比較基準，不以 R² 判斷模型好壞
GARCH 能捕捉「波動聚集」、評估風險原始價格模型的 95% 預測區間涵蓋率只有 63.8%；改用對數價格後為 94.2%，但換成 0050.TW 仍只有約 88%，顯示波動度會隨時間改變，GARCH 類模型是下一步
務必以 Naive 為對照組，並採滾動式樣本外驗證本作業已以 Naive 為對照組，並依時間切分、每天用真實歷史值做一步預測；尚未做多個起點的滾動驗證，列為未來改進
改為預測報酬率或漲跌方向網頁已計算漲跌方向準確率（52.8%，接近擲硬幣）；以報酬率為目標並加入技術指標的模型列為未來改進

十、結論與限制

  • 以 AIC／BIC 選出的 AR(1) 模型 φ₁ ≈ 1.0006，台積電股價接近隨機漫步；測試期 RMSE 41.762 僅略優於 Naive 的 41.908。
  • 建模尺度對不確定性影響很大：對數價格讓 95% 預測區間涵蓋率從 63.8% 提升到 94.2%。
  • 平台滿足兩個加分項：下拉選單切換兩種問題、可任意更換資料來源（股票代號、CSV 網址、上傳）。
  • 限制：AR 假設誤差變異數固定，市場波動度改變時預測區間仍會失準（例如 0050.TW 的涵蓋率為 88%）；未來日期只排除週末、未扣除國定假日；外部 CSV 需允許跨網域讀取。
  • 未來改進：依 NotebookLM 摘要的建議，改以報酬率或漲跌方向為預測目標、採滾動式樣本外驗證（Rolling Walk-Forward），並加入 GARCH 波動度模型與成交量等外生變數（ARX）。
